# CHANTIER 404 — Bac Pro MELEC

Jeu pédagogique interactif destiné aux apprentis Bac Pro MELEC : canalisations électriques, va-et-vient, étude de cas, remédiation, personnages, chronomètres, rapport individuel et restitution orale.

## Mise en ligne

Déposer `index.html` (jeu apprenti) et `formateur.html` (accès formateur direct) à la racine de ce dépôt, puis activer **Settings → Pages → Deploy from a branch → main / (root)**.

Accès prévus après publication :
- Apprenti : https://bapmoron-cmd.github.io/chantier-404/
- Formateur : https://bapmoron-cmd.github.io/chantier-404/formateur.html

**Attention :** l'édition formateur est un accès pratique non sécurisé par serveur ; ne pas en faire un moyen de protéger des corrigés confidentiels.
